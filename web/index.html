    How it was tested, and its limits

    Tested

    • The replay is one run on a regtest chain with real Zebra consensus and Orchard notes.
    • The testnet numbers come from a 112,788-block testnet wallet, timed end to end.
    • The ZeWIF result is from zcash_client_sqlite's own importer, unmodified.
    • The lab runs Hermit's kernel itself. Keys are generated in your browser and every section is really encrypted with age.

    Limits

    • Fast switching needs a wallet built on zcash_client_sqlite: Zallet, the mobile SDKs, zcash-devtool.
    • Zallet has the ZeWIF importer but no command to import a file yet.
    • Storage still sees device names and public keys, anchors, section names, padded sizes and timing.
    • Revocation is forward-only: a revoked device keeps what it already decrypted.
